Login Page with List, Table, and Iframe

Project Description
This project is a simple website created using HTML and CSS. It contains a login page that takes the user to the index page, where they can navigate to different pages using links.

Pages Included
- Login Page: Allows users to enter their details.
- Index Page: Contains links to navigate between webpages.
- List Page: Displays ordered and unordered lists.
- Table Page: Displays information in rows and columns.
- Iframe Page: Demonstrates how to display one webpage inside another webpage.

Technologies Used
- HTML5
- CSS3

What I Learned
Through this assignment, I learned how to create HTML forms, use anchor tags for navigation, display lists and tables, and use iframes to embed webpages.

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open Login.html in a web browser.
4. Navigate to the other pages using the links.
